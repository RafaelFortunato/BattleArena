# Battle Arena

A top-down survivors-style arena game. You play a wizard husky, hold off waves of monsters with spells, complete missions, and beat the boss at the end of the match. Built with Unity 6 (URP) for WebGL.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move | WASD / arrow keys | Left stick |
| Spells | Q / E / R | X / Y / B |
| Interact | F | A |
| Pause | Esc / Enter | Start |

## Project notes

- Unity **6000.5.2f1**.
- The scene, prefabs and game data are generated by **BattleArena → Build Game Content** (`Assets/Game/Scripts/Editor/ContentBuilder`). Balance values live there too.
- The player character's Blender source is in `SourceArt/WizardHusky`.
